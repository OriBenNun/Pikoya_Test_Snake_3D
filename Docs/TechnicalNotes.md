# Garden Snake — technical notes

## Stack and assets

- Unity 6000.6.0f1, C#, Universal Render Pipeline, Unity Input System, uGUI / TextMeshPro, and Unity Test Framework.
- Unity Pipeline is installed as an Editor automation tool. The game code has no dependency on its APIs.
- All eight 3D assets were generated in Blender 3.5 with the included Python source: snake head, body, tail, apple, garden tile, planter, flower, and rock. The `.blend` file is editable and FBX exports are committed project assets.
- Materials, lighting, scene layout, and particle effects are authored by the Unity scene builder. No stock model pack or image-generation service is used.
- Four sound effects are original mathematical synthesis, generated by `Tools/generate_audio.py`: turn, pickup, start, and loss. No sampled recordings or third-party audio pack is used.
- Liberation Sans is distributed with Unity's TMP Essential Resources and used under the included SIL Open Font License. TMP shader sources come from that same installed uGUI package. `Tools/extract_tmp_resources.py` records the extraction process. Unity generates the TMP settings and font atlas; no serialized asset YAML is handwritten.
- Existing project/template files and packages remain in place. No paid plugin is required.

## Implementation decisions

The simulation uses integer grid cells with a fixed gameplay tick. Rendering interpolates between previous and current cells each frame. This keeps collisions deterministic while movement looks smooth. Input stores up to two turns and validates each against the last queued heading, preventing both reversal and accidental dropped corners.

Food is selected uniformly from free cells with a bounded scan. It never uses an unbounded random retry loop, including near a full board. The tail's previous cell is legal to enter on a non-growth tick. Filling every cell produces a win state instead of attempting another food spawn.

Presentation stays separate from the simulation: apple bob/spin, a growth pulse along the snake, confetti, short pitched pickup sounds, a small decaying camera kick, and fast UI transitions. Motion and speed settings are serialized for tuning. Segment objects are reused across restarts; new objects are only added when exceeding the previous run's length. No physics colliders are needed for grid rules.

The web template includes loading progress, a keyboard focus target, capped pixel density, and a load-error display. Local best score and mute preference use PlayerPrefs; there is no backend, login, analytics, or network gameplay. Uncompressed WebGL output favors straightforward hosting over download size.

## AI usage

OpenAI Codex assisted substantially with all new Garden Snake C# scripts, regression tests, Editor automation, Blender generation code, audio synthesis code, web template, tooling, and documentation. The Blender geometry, generated sounds, visual direction, and tuning were created through those AI-assisted scripts. Font and TMP shaders are existing third-party resources, not AI-generated assets. No human-authored claim is made for the new implementation.
